# Native decompiler and verification

This describes the historical v0.3.2 exact certificate. For current verification states, normalized CFG rules and numeric-payload support, use [verification-v0.3.3.md](verification-v0.3.3.md). Current reports emit `UNVERIFIED` for an inconclusive check.

The patch changes CFG reachability/dominator/postdominator analysis, natural-loop discovery, threaded loop exits, return/break/continue range termination, closed branch-region selection, operand-use multiplicity, join-variable and loop-exit lifetimes, and emitter statement separators. It does not insert `do ... end` around terminators or repair source text after lifting. `assets/luaudec-source/` preserves the modified native sources; the patch applies to the pinned upstream commit in INSTALL.md. Undefined-register diagnostics are snapshot-aware and emitted after lifting, so enabling diagnostics cannot change speculative condition matching.

`setup` builds pinned Luau, patched luaudec, the authored-test VM, and native CFG/emitter invariant tests. `recover` and `regression` use that same recovery pipeline. Bundled tools enable compile-only CFG audits; custom older adapters without `cfg_audit` retain `NOT_CHECKED` rather than a fabricated certificate.

The v3 certificate compares reachable instruction graphs after recompilation at O1/O2. It permits bijective register renaming, constant-pool renumbering, unconditional jump threading, predicate inversion with successor exchange, and ignored coverage/prologue instructions. FASTCALL builtin IDs, explicit/implicit register operands, guarded fallback CALL and both CFG edges are retained. It retains distinct prototype references and cached closure/table constant slots, even when their bodies/values are identical. It checks return arities, call arguments/results, full string bytes, constants and referenced closure graphs. A whole module is `CFG_VALIDATED` only when its main graph, including referenced closures, matches. Per-function matches assume the same ordered upvalue and external closure-cache environment; they do not prove surrounding capture bindings unless the parent graph also matches. An unmatched or unsupported form is `UNVERIFIED`, not a demonstrated semantic failure. The checker is conservative and is not a general equivalence theorem prover. Source locations, debug names and timing/coverage observations are outside this instruction certificate; it is not a guarantee of debug/profiling API behavior. `cfg-audit/` preserves original/recompiled instructions, CFGs, bytecode and comparisons. Independent negative controls include FASTCALL ID and target mutations, changed predicates, calls, captures, return values and long constants. Exact vector/NaN bit metadata is unavailable, so those constants remain uncertified.

`SYNTAX_VALID`, `CFG_VALIDATED`, and `BEHAVIOR_VERIFIED` are separate evidence. Behavioral verification covers only authored fixture inputs and observed stdout/exit status. It does not cover all inputs, Roblox engine scheduling, network, physics or third-party behavior. Real game code is never executed by these tests. Absence of warnings is not semantic proof.

The collector retains strict before/after path validation and stable double reads. New observations include first-seen and validation time/address/class/name/parent, plus `node_unreadable`, `class_changed`, `name_changed`, `parent_chain_invalid`, `wrong_datamodel`, `object_destroyed_or_replaced` or `unknown` when applicable. Destruction/replacement is an identity-change diagnosis (self pointer/vtable), not proof of the allocator's history. Workspace scripts are checked first; inventory JSON writing is deferred until after buffer capture. Earlier missing observations cannot be reclassified without retained diagnostics. This diagnostic change has simulated tests; no new live capture was performed in v0.3.2.

Windows x64 is the tested build/runtime environment. The existing unlisted-Player best-effort policy remains; other Player versions, OS collectors, future bytecode versions and arbitrary control-flow patterns remain unverified.
