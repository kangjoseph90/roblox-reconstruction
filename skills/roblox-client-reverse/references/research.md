# Research and experimental findings

Checked 2026-11-11. Repository commits and observed behavior take precedence over README claims. No Sell Lemons runtime collection was performed. No account credentials were accessed.

## Architecture findings

1. **Representation and execution.** LocalScript, ModuleScript and Script are source-container instance classes. Script can run on the client when RunContext is Client (enum value 2); class alone is insufficient. ModuleScripts do not establish client/server use by themselves. Static classification must also consider ancestor services. Sources: [script locations](https://create.roblox.com/docs/scripting/locations), [RunContext values](https://create.roblox.com/docs/reference/engine/enums/RunContext).
2. **Visibility after joining.** Replicated executable code can be examined in principle even when disabled or never run. Server-only code in ServerStorage/ServerScriptService does not become client code. This is an architectural exposure statement, not a supported public source-download API. Source: [Roblox confidentiality and replication](https://create.roblox.com/docs/scripting/security/access-control).
3. **Offline files.** Studio exports place data as compact binary `.rbxl` or XML `.rbxlx`; model equivalents share the serialization family. These can contain Source text, so no decompilation is needed. Source: [official place files documentation](https://create.roblox.com/docs/projects/place-files).
4. **Serialization.** The community rbx-dom format specification describes binary version 0, INST/PROP/PRNT and shared strings, LZ4/ZSTD chunks, and Bytecode property type `0x1d`. XML uses ProtectedString for source. These are artifact formats, not a specification of the current network wire protocol or a guarantee that Player caches contain recoverable place files. Sources: [binary specification](https://github.com/rojo-rbx/rbx-dom/blob/7a6ca296e25ea4dddd44b08449ceac58ae5c2476/docs/binary.md), [XML specification](https://github.com/rojo-rbx/rbx-dom/blob/7a6ca296e25ea4dddd44b08449ceac58ae5c2476/docs/xml.md).
5. **Public acquisition.** Metadata lookup identifies a place's universe and creator without joining. A source artifact is a separate permission-controlled download. Copy-enabled games expose an editable-copy Studio workflow. Roblox's 2025 asset-delivery change requires authentication in general; exceptions cannot be relied upon. Sources: [copy settings](https://create.roblox.com/docs/projects/configure-experiences), [official asset-delivery announcement](https://devforum.roblox.com/t/creator-action-required-new-asset-delivery-api-endpoints-for-community-tools/3574403).
6. **Compiled forms.** Upstream Luau has versioned serialized bytecode, type-information revisions, instruction/prototype/constant data and optional debug information. Deployed Roblox artifacts may have additional encoding/signing/wrapping; upstream compiler output is not proof of deployed Player compatibility. This pipeline preserves unknown bytes and requires an established encoding profile. Sources: [bytecode definitions](https://github.com/luau-lang/luau/blob/f46d879e28302a430029304f7f6a162aed66f103/Common/include/Luau/Bytecode.h), [loader](https://github.com/luau-lang/luau/blob/f46d879e28302a430029304f7f6a162aed66f103/VM/src/lvmload.cpp).
7. **Loss through compilation.** Comments, formatting and full original type syntax are unavailable from runtime instructions. Variable/debug names and line data depend on compiler/debug settings. Optimization can eliminate or rewrite constructs, so regenerated structured source need not resemble the original and a recompile does not prove equivalent behavior. Sources: [compiler options](https://github.com/luau-lang/luau/blob/f46d879e28302a430029304f7f6a162aed66f103/Compiler/include/Luau/Compiler.h), and controlled O0/O1/O2 results below.
8. **Runtime and memory.** Official heap tooling exposes allocations, object types and reference paths. Its documentation does not promise a full source or serialized-bytecode dump. Upstream VM Proto structures are build-specific in-memory objects; reconstructing them from a process snapshot differs from capturing a serialized buffer at the loader boundary. Sources: [memory/heap tooling](https://create.roblox.com/docs/studio/optimization/memory-usage), [VM object definitions](https://github.com/luau-lang/luau/blob/f46d879e28302a430029304f7f6a162aed66f103/VM/src/lobject.h).
9. **Incomplete observations.** Workspace streaming can load/unload content around replication foci. Runtime-created, conditionally replicated, per-player and destroyed/unparented objects need separate observation plans; a single client snapshot cannot establish game completeness. Source: [instance streaming](https://create.roblox.com/docs/workspace/streaming).

## Experiments and interpretation

- **Independent format interoperability:** two unrelated owned fixture places include ModuleScripts, a Client RunContext Script, LocalScript, duplicate names, path-like/HTML names, true server containers, a similarly named ordinary Folder, empty and absent source. rbx-util generated real compressed binary artifacts from the XML. Reader recovered hierarchy/classes/source and preserved exact originals. The binary serializer filled an omitted Source with an empty default; that is recorded as empty rather than falsely inferred absent.
- **Compression and bytecode:** independently generated binary payloads were repacked into uncompressed/LZ4/ZSTD chunks and yielded identical parsed instances. Synthetic `0x1d` properties survived as exact opaque bytes. These field-preservation fixtures are not signed Roblox production bytecode.
- **Decompiler:** simple fixture and structured fixture at O1, plus structured at O0/O2, all upstream v14/type-v3. Actual recovered outputs recompiled; owned-source stdout matched (`42` and `18\t3\tAda`). Type annotations were not reconstructed. Four cases are a bounded behavioral check, not a universal proof.
- **Owned host capture:** the pinned compiler API produced a 683-byte v13/type-v3 container, whereas its CLI produced v14 in the earlier experiment. This is an observed route difference; no cause is assumed. The host captured exactly the buffer passed to `luau_load`. Captured bytecode decompiled and recompiled, and host/original/recovered stdout matched. The bootstrap profile accepts these two observed bytecode versions only. The packaged host runner reproduces this boundary using only its bundled fixture.
- **Negative checks:** unsupported versions/encoding, absent source, invalid source, malformed/truncated input, cycles/dangling references, dangerous/duplicate names, symlinks, integrity tampering, HTTP/embedded authentication errors and credential-free CDN follow-up are tested. See packaged tests and the accompanying evaluation report for counts.
- **External target:** Sell Lemons place `79268393072444`, universe `7395930870`, creator BloxByte Games (`4619164`) resolved via actual public responses. Metadata says copyingAllowed=false. Asset delivery HTTP 200 contained error code 401/customErrorCode 11. Zero game source artifacts acquired; the correct outcome is metadata-only/access-denied. Prior `roblox-research` contains third-party automation scripts, not an authenticated original client dump; they were not relabeled or analyzed as original game source.
